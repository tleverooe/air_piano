# 空中钢琴 Air Piano

用摄像头识别手指，在空中弹钢琴。纯网页，不用安装任何东西。

## 怎么弹

1. 用笔记本的前置摄像头，正常对着你坐好。
2. 打开网页，点「开始」，允许使用摄像头。
3. 画面下方是一台平放在桌上的钢琴，像是钢琴后面立了一面镜子，你看到的是镜子里的样子：
   - 左右和你一致：低音在左手边，高音在右手边。
   - 前后是反的：黑键那一侧靠近电脑，在画面下方；白键前沿靠近你，在画面上方。
4. 用正常弹琴的姿势：手背放平，手悬在琴键上方，**手指往下按**就会响，抬起来声音松开。
5. 有两种弹法，在设置里的「弹法」切换：
   - **手掌定位（默认）**：每只手盖住 5 个相邻的白键，就是手底下那 5 个，大拇指到小拇指从左到右各管一个。左右移动整只手来换到别的音。**整只手往前推两三厘米**（朝屏幕方向，跟平时手悬着的位置比），每根手指就升半音，弹它那个白键右边的黑键（E 和 B 右边没有黑键，保持不变）；收回来就变回白键。每个指尖上方会显示它现在管的是哪个音。不用拿指尖去对准键，最好弹。
   - **指尖对准**：指尖悬在哪个键上，按下去就弹哪个键，黑键也能弹，但要对得准。
   - 两种弹法都是每根手指只跟它自己平时放松的位置比，所以手指长短不一样没关系，手停着不会响；被旁边手指带着动的手指也不会响。

## 设置

- **弹法**：手掌定位 / 指尖对准，见上面。
- **最低音 / 最高音**：选键盘的范围（C2 到 C7），默认 C3 到 C5。
- **显示黑键**：默认打开；关掉就只有白键。手掌定位模式下要往前推手才能弹黑键，所以这个要打开。
- **键盘位置**：把键盘在画面里往上或往下挪，让琴键正好落在你指尖下面。
- **灵敏度**：调高了手指轻轻弯一点就响；容易误触就调低。

- **调试显示**：每个指尖旁边显示一根竖条，表示这根手指按下去多深，超过白线就会响；手掌位置显示一根横条，表示手往前推了多少，满了就切到黑键。弹不出来的时候打开看看。

设置会记在浏览器里，下次打开还在。

## 小提示

- 摄像头要能看到手指往下弯的动作，所以手背朝上、手掌朝下效果最好。
- 光线亮一点、背景简单一点，识别会更稳。
- 白键太多（超过 20 个左右）手指会不好对准。

## 部署到 GitHub Pages

仓库 Settings → Pages → Build and deployment，Source 选 **Deploy from a branch**，Branch 选 `main`、目录 `/ (root)`，保存。
一两分钟后就能在 `https://tleverooe.github.io/air_piano/` 打开。

摄像头只能在 https 或 localhost 下使用，所以直接双击打开本地的 `index.html` 是不行的。本地测试可以在项目目录运行：

```
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。

## 用到的东西

- [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)：手部 21 个关键点识别
- [Tone.js](https://tonejs.github.io/)：播放声音
- Salamander Grand Piano：钢琴采样（由 Tone.js 托管）
