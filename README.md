# 空中钢琴 Air Piano

用摄像头识别手指，在空中弹钢琴。纯网页，不用安装任何东西。

## 怎么弹

1. 用笔记本的前置摄像头，正常对着你坐好。
2. 打开网页，点「开始」，允许使用摄像头。
3. 想象屏幕前面竖着立了一块钢琴键盘，正对着你，黑键在上面一排。
4. 手指对准画面里的某个键，**往前伸（朝屏幕方向）**，指尖碰到那块看不见的键盘时就会响；往回收，声音松开。
   - 指尖对着哪个键，那个键会有金色描边，伸过去弹的就是这个键。手指停在里面不动，音会一直按着，不会跳到旁边的键。
   - 每个指尖外面有一个金色圆圈，离按键平面越近圈越小，碰到平面时变成实心的金点。
   - 伸得越快，声音越响。
   - 两只手、十根手指都可以同时弹。
5. 第一次用建议先点 **「设定平面」**：3 秒倒数后，把指尖伸到你觉得舒服的按键位置停住，平面就会设在那里。

## 设置

- **最低音 / 最高音**：选键盘的范围（C2 到 C7），默认 C3 到 C5。
- **显示黑键**：默认打开；关掉就只有白键。
- **键盘位置**：把键盘在画面里往上或往下挪。
- **按键平面离镜头**：按键平面离摄像头多少厘米。总是误触就调小（平面离镜头更近，要伸更远才响），伸到头还不响就调大。
- 「设定平面」下面会实时显示离镜头最近的手指有多远，可以用来对照调整。

设置会记在浏览器里，下次打开还在。

## 关于距离

单个摄像头测不出真实距离，这里是根据手在画面里的大小，再加上 MediaPipe 给的手指前后偏移估算的，只是个大概值。手比一般人大或小、摄像头视角不同，显示的厘米数都会有偏差。不影响使用，用「设定平面」或滑块按你的实际感觉调就行。

## 小提示

- 光线亮一点、背景简单一点，识别会更稳。
- 手离摄像头 30 到 60 厘米效果比较好。
- 手掌尽量正对镜头，手指往前伸时不要被手掌挡住。
- 白键太多（超过 20 个左右）手指会不好对准。

## 部署到 GitHub Pages

仓库 Settings → Pages → Build and deployment，Source 选 **Deploy from a branch**，Branch 选 `main`、目录 `/ (root)`，保存。
一两分钟后就能在 `https://tleverooe.github.io/air_piano/` 打开。

摄像头只能在 https 或 localhost 下使用，所以直接双击打开本地的 `index.html` 是不行的。本地测试可以在项目目录运行：

```
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。

## 用到的东西

- [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)：手部 21 个关键点识别
- [Tone.js](https://tonejs.github.io/)：播放声音
- Salamander Grand Piano：钢琴采样（由 Tone.js 托管）
